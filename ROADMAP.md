# Roadmap

Aster reads and writes Markdown files on this Mac. It has no account. Notes stay in those files.

## Available now

The [1.0.5 release](https://github.com/Kasakir-AI/Aster/releases/tag/v1.0.5) is available on GitHub and Homebrew. The downloads are signed with Developer ID and notarized by Apple. A Mac App Store edition is in Apple's review. See the [changelog](CHANGELOG.md) for shipped changes.

## Next

- Release the Mac App Store edition after Apple's review.
- Confirm Finder previews, thumbnails, and the Xcode preview command in the store edition.

## Later

- Refresh workspace search when a draft is discarded or a file changes on disk.
- Give the editor more room when the workspace and outline are both open.
