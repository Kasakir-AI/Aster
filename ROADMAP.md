# Roadmap

Aster 0.2.2 is the current release. The items below are under consideration.

- Sandbox the editor, and remember the folders you choose.
- Add a setting that opens document links only inside the workspace.
- Add wikilinks between notes in a workspace.
- Add a copy button on a code block.
- Show a word count for the open note.
- Remember a view mode on each document.
- Notarize Aster with a Developer ID when a certificate is available. Until then, downloads stay ad hoc signed.

Report a bug or send a change from the [contributing](README.md#contributing) section of the README.
